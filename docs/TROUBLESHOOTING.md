# Решение проблем

## Ошибка: "ClientException: Failed to fetch"

Эта ошибка обычно возникает из-за проблем с сетевыми запросами на веб-платформе.

### Возможные причины:

1. **Проблемы с подключением к интернету**
   - Проверьте, что у вас есть активное подключение к интернету
   - Попробуйте открыть https://reqres.in/api/login в браузере

2. **CORS (Cross-Origin Resource Sharing) проблемы**
   - ReqRes API обычно не имеет проблем с CORS
   - TMDB API также поддерживает CORS
   - Если проблема сохраняется, проверьте консоль браузера (F12)

3. **Таймаут запроса**
   - Запросы имеют таймаут 30 секунд
   - Если проблема сохраняется, возможно, API недоступен

4. **Неправильный URL**
   - Убедитесь, что API доступны:
     - https://reqres.in/api
     - https://api.themoviedb.org/3

### Решения:

1. **Проверьте консоль браузера (F12)**
   - Откройте Developer Tools (F12)
   - Перейдите на вкладку "Console"
   - Посмотрите на детали ошибки

2. **Проверьте вкладку Network**
   - Откройте Developer Tools (F12)
   - Перейдите на вкладку "Network"
   - Попробуйте выполнить запрос
   - Посмотрите статус запроса

3. **Проверьте подключение к API**
   - Откройте в браузере: https://reqres.in/api/users?page=1
   - Должен вернуться JSON с данными

4. **Очистите кэш браузера**
   - Нажмите Ctrl+Shift+Delete
   - Очистите кэш и cookies
   - Перезагрузите страницу

5. **Попробуйте другой браузер**
   - Chrome
   - Firefox
   - Edge

### Если проблема сохраняется

1. Проверьте, что вы используете правильные тестовые данные
2. Проверьте консоль браузера на наличие других ошибок
3. Убедитесь, что API доступны (проверьте в браузере)
4. Попробуйте запустить приложение в режиме разработки:
   ```bash
   flutter run -d chrome --web-port=8080
   ```
