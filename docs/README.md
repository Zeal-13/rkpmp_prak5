# Документация архитектуры приложения Movie Management App

## Структура документации

Этот каталог содержит документацию по архитектуре и структуре приложения Movie Management App.

### Файлы документации:

1. **`business_screens.md`**
   - Описание 7 основных бизнес-экранов приложения
   - Подробное описание функциональности каждого экрана
   - Информация о том, с какими данными работает каждый экран
   - Навигационные связи между экранами

2. **`route_map.xml`**
   - Диаграмма навигации в формате Draw.io
   - Визуальное представление всех маршрутов приложения
   - Цветовые схемы для разных типов навигации
   - Можно открыть в Draw.io онлайн или в приложении

3. **`route_map_text.md`**
   - Текстовое представление карты маршрутов
   - ASCII-диаграмма навигации
   - Описание типов навигации
   - Стек навигации и особенности реализации

4. **`state_storage_choice.md`**
   - Анализ требований к хранению состояния
   - Сравнение различных решений (shared_preferences, hive, drift)
   - Рекомендация по выбору пакетов
   - План интеграции выбранного решения
   - Примеры кода для интеграции

## Быстрый старт

### Просмотр диаграммы навигации

1. Откройте файл `route_map.xml` в Draw.io:
   - Онлайн: https://app.diagrams.net/ → File → Open → выберите `route_map.xml`
   - Или откройте напрямую через VS Code с расширением Draw.io Integration

2. Альтернатива: откройте `route_map_text.md` для текстового представления

### Изучение бизнес-экранов

Откройте `business_screens.md` для детального описания:
- 7 основных бизнес-экранов
- Функциональность каждого экрана
- Связи между экранами и данными

### Выбор пакета для хранения состояния

Изучите `state_storage_choice.md` для:
- Рекомендаций по выбору пакетов
- Сравнительного анализа решений
- Плана внедрения

## Основные выводы

### Бизнес-экраны (7 штук)

1. **Auth/Register Screen** - Авторизация и регистрация
2. **Movies List Screen** - Список фильмов (Tab 1)
3. **Add Movie Screen** - Добавление нового фильма
4. **Movie Detail Screen** - Детальная информация о фильме
5. **Movie Review Screen** - Отзывы о фильме
6. **Profile Screen** - Профиль пользователя (Tab 2)
7. **Settings Screen** - Настройки приложения (Tab 3)

### Навигация

- **Только routed navigation** - все переходы используют Flutter Navigator
- **3 типа навигации**: Вертикальная (смена экранов), Горизонтальная (вкладки), Модальная
- **Главный экран** использует BottomNavigationBar с IndexedStack для сохранения состояния вкладок

### Хранение состояния

**Рекомендуемое решение:**
- `shared_preferences` - для настроек и флагов
- `hive` - для коллекций фильмов и данных пользователя
- Интеграция с существующим `flutter_riverpod`
