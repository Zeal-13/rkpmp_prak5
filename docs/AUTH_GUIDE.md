## Решение проблем

### Проблема: "Ошибка при входе"
- Убедитесь, что используете правильные тестовые данные
- Проверьте подключение к интернету
- Проверьте, что API доступен (https://reqres.in/)

### Проблема: Не переходит на главный экран после авторизации
- Убедитесь, что авторизация прошла успешно (нет сообщений об ошибке)
- Проверьте консоль браузера на наличие ошибок
- Попробуйте обновить страницу

### Проблема: CORS ошибки
- ReqRes API обычно не имеет проблем с CORS
- Если возникают CORS ошибки, проверьте консоль браузера

## Структура авторизации

Приложение использует:
1. **ReqRes API** для сетевых запросов (login/register)
2. **SharedPreferences** (на веб) или **Drift/SQLite** (на нативных платформах) для локального хранения сессии
3. **Riverpod** для управления состоянием

После успешной авторизации:
- Пользователь сохраняется локально
- Состояние `isAuthenticated` устанавливается в `true`
- `AppContainer` автоматически показывает главный экран
