# Настройка для веб-платформы

## Изменения для поддержки веб

Приложение было адаптировано для работы на веб-платформе. Основные изменения:

### 1. База данных
- **Нативные платформы**: Используется Drift с SQLite
- **Веб-платформа**: Используется SharedPreferences вместо базы данных

### 2. Data Sources
Созданы альтернативные реализации для веб:
- `AuthSharedPrefsDataSource` - для аутентификации
- `MoviesSharedPrefsDataSource` - для фильмов

### 3. Условная компиляция
DI контейнер автоматически выбирает правильную реализацию в зависимости от платформы:
```dart
kIsWeb
  ? AuthSharedPrefsDataSource(...)
  : AuthDriftDataSource(...)
```

## Запуск на веб

### Способ 1: Через VS Code
1. Нажмите `F5`
2. Выберите конфигурацию "Flutter (Web)"
3. Приложение откроется в Chrome

### Способ 2: Через терминал
```bash
flutter run -d chrome
```

### Способ 3: С указанием порта
```bash
flutter run -d chrome --web-port=8080
```

## Особенности веб-версии

1. **База данных**: Не используется на веб (только SharedPreferences)
2. **Сетевые запросы**: Работают через HTTP API
3. **Хранение данных**: Используется LocalStorage через SharedPreferences

## API запросы

Все 5 сетевых запросов работают на веб:
- ✅ Поиск фильмов (TMDB)
- ✅ Популярные фильмы (TMDB)
- ✅ Детали фильма (TMDB)
- ✅ Регистрация (ReqRes)
- ✅ Вход (ReqRes)

## Решение проблем

### Проблема: CORS ошибки
Если возникают CORS ошибки при запросах к API, это нормально для некоторых API. TMDB и ReqRes обычно работают без проблем.

### Проблема: База данных не работает
На веб-платформе база данных не используется - это нормально. Все данные хранятся через SharedPreferences.
