# Решение проблемы CORS на веб-платформе

## Проблема

При запуске приложения на веб-платформе могут возникать ошибки CORS (Cross-Origin Resource Sharing), которые блокируют запросы к внешним API.

## Решения

### Решение 1: Запуск Chrome с отключенной проверкой CORS (только для разработки!)

**Windows:**
1. Закройте все окна Chrome
2. Запустите скрипт `scripts/run_chrome_no_cors.bat`
3. Или вручную:
   ```cmd
   start chrome.exe --user-data-dir="C:/temp/chrome_dev_session" --disable-web-security --disable-features=VizDisplayCompositor
   ```
4. Затем запустите приложение:
   ```bash
   flutter run -d chrome
   ```

**Linux/Mac:**
1. Закройте все окна Chrome
2. Запустите скрипт `scripts/run_chrome_no_cors.sh`
3. Или вручную:
   ```bash
   google-chrome --user-data-dir="/tmp/chrome_dev_session" --disable-web-security --disable-features=VizDisplayCompositor
   ```
4. Затем запустите приложение:
   ```bash
   flutter run -d chrome
   ```

**⚠️ ВАЖНО:** Используйте этот метод ТОЛЬКО для разработки! Никогда не используйте браузер с отключенной безопасностью для обычного просмотра.

### Решение 2: Использование прокси для разработки

Если первый способ не работает, можно использовать прокси-сервер для обхода CORS:

1. Установите CORS прокси (например, `cors-anywhere`)
2. Настройте API клиент для использования прокси в режиме разработки

### Решение 3: Проверка доступности API

Убедитесь, что API доступны и поддерживают CORS:

1. **ReqRes API** - обычно поддерживает CORS
   - Проверьте: https://reqres.in/api/users?page=1
   - Должен вернуть JSON без ошибок CORS

2. **TMDB API** - поддерживает CORS
   - Проверьте: https://api.themoviedb.org/3/movie/popular?api_key=YOUR_KEY
   - Должен вернуть JSON без ошибок CORS

### Решение 4: Использование расширения браузера

Для Chrome можно использовать расширение "CORS Unblock" или "Allow CORS" (только для разработки).

## Проверка работы

1. Откройте Developer Tools (F12)
2. Перейдите на вкладку "Network"
3. Попробуйте выполнить запрос (войти или зарегистрироваться)
4. Проверьте статус запроса:
   - ✅ 200 OK - запрос успешен
   - ❌ CORS error - проблема с CORS
   - ❌ Failed to fetch - проблема с сетью

## Альтернативное решение для продакшена

Для продакшена рекомендуется:
1. Использовать собственный backend-прокси
2. Настроить CORS на сервере API (если у вас есть доступ)
3. Использовать серверную аутентификацию вместо клиентской

## Дополнительная информация

- CORS - это механизм безопасности браузера
- ReqRes и TMDB API обычно поддерживают CORS
- Проблемы могут возникать при локальной разработке
- В продакшене обычно проблем с CORS нет
