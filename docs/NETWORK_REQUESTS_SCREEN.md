# Экран сетевых запросов

## Описание

Создан отдельный экран для тестирования всех сетевых запросов приложения. Экран доступен из раздела "Настройки".

## Расположение

**Файл:** `lib/features/network/presentation/pages/network_requests_page.dart`

**Навигация:** Настройки → Сетевые запросы

## Реализованные запросы

### 1. TMDB API - Поиск фильмов
- **Use Case:** `SearchMoviesUseCase`
- **Параметры:** Текстовый запрос
- **Функционал:** Поиск фильмов по названию через TMDB API
- **Результат:** Список найденных фильмов (первые 3)

### 2. TMDB API - Популярные фильмы
- **Use Case:** `GetPopularMoviesUseCase`
- **Параметры:** Нет
- **Функционал:** Получение списка популярных фильмов
- **Результат:** Список популярных фильмов (первые 3)

### 3. TMDB API - Детали фильма
- **Use Case:** `GetMovieDetailsUseCase`
- **Параметры:** ID фильма (число)
- **Функционал:** Получение подробной информации о фильме
- **Результат:** Детальная информация о фильме

### 4. ReqRes API - Вход пользователя
- **Use Case:** `LoginUseCase`
- **Параметры:** Email и пароль
- **Функционал:** Аутентификация через ReqRes API
- **Результат:** Информация о пользователе

## Интерфейс

Каждый запрос представлен в отдельной секции с:
- Заголовком с иконкой
- Полями ввода (если требуются)
- Кнопкой для выполнения запроса
- Индикатором загрузки
- Отображением результатов или ошибок

## Использование

1. Откройте приложение
2. Перейдите в "Настройки" (третья вкладка)
3. Нажмите на "Сетевые запросы"
4. Выберите нужный запрос и заполните параметры
5. Нажмите кнопку для выполнения запроса
6. Просмотрите результаты или ошибки

## Особенности

- Все запросы выполняются асинхронно
- Показываются индикаторы загрузки
